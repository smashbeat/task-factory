# size-set pack: implementation plan

**Goal:** a `size-set` domain pack (garment measurement intake) built on the shared PDF forge, through to a seed 1 task and a Sonnet screen.

**Spec:** `docs/size-set-design.md`. **Architecture:** extract the domain-free forge from `packs/coa/render.py`; add the pack (rules and features as data, model with truth and mutants, four templates, reference, tests); build with the existing pipeline.

**Global constraints:** no em dashes in any text that ships; vendor and brand names invented; numeric truths are integer counts of the house precision; the coa pack's output must not change (byte or pixel identical re-render of build 1k).

## Tasks

### Task 1: extract docforge
- Create `src/taskfactory/forge/__init__.py`, `src/taskfactory/forge/docforge.py`: `Pen`, `wrap`, `set_meta`, `rasterize`, `scan_sim`, `jpeg_bytes`, `image_pdf`, `ocr_layer`, `replace_page_images`, `stamp_image`, `freetext_correction`, `page_count`, `find_word`, `SCAN_ROUTES`, `LETTER`, `A4`, and `finish(route, base, path, rnd, meta, size, wrong_base=None)` for the digital, distilled, outlined and scan routes (`wrong_base` is a callable returning the altered base for `scan_wrong_ocr`, called after the page seeds are drawn so the rng stream is unchanged).
- Modify `packs/coa/render.py` to import them. `tests/test_coa_render.py` and the probe mount `/tf/src`.
- Test: re-render build 1k (41 items) before and after; every file byte-identical, or pixel- and text-identical where the route is nondeterministic on its own.
- Commit.

### Task 2: the pack's model and declaration
- Create `packs/size-set/pack.toml` (11 rules, 36 features, 4 styles, 9 routes, `images` pointing at the coa envs), `packs/size-set/model.py` (catalogue of garments, points, size ranges, houses; `Report` with `spec`, `truth(off)`; `apply_features`; number helpers `parse_qty`, `fmt_qty`, `to_house`), `packs/size-set/pack.py`, `packs/size-set/instruction.md`.
- Test `tests/test_size_model.py`: fraction and decimal parsing and formatting; conversion and rounding at the edge; half measures; revisions in date order with `rev_late` ignored; grading from base; decision ladder; every mutant rule changes some item's truth; pack gate and a seed 1 plan pass the builder gates.
- Commit.

### Task 3: the renderer
- Create `packs/size-set/render.py`: four templates on `docforge.Pen`, re-measurement block and page, stamps, white decoy, correction annotation, form route, `render_item`.
- Test `tests/test_size_render.py` with `tests/probes/size_render_probe.py` in the gen image: every route draws; a stamp covers no printed word; the correction covers only the number; the wrong-OCR layer differs from the page; the form's stored values differ on `form_mismatch`; landscape pages come out landscape.
- Commit.

### Task 4: the task directory and reference
- Create `packs/size-set/task/` from the coa template: `task.toml`, `environment/Dockerfile`, `tests/{Dockerfile,test.sh,test_outputs.py,compare.py}` (numeric fields as exact rationals), `solution/{intake.py,solve.sh}`.
- Test: `compare.py` accepts `20 1/4`, `20.25` and `81/4` as one value; the reference passes the seed 1 build.
- Commit.

### Task 5: build and screen
- `taskfactory build packs/size-set --seed 1 --out out/build-set-1 --docker --fix`, holdouts at 90%.
- Harbor: oracle, nop, Sonnet 5.5 at a 2 h cap. Report; frontier trials wait for my go-ahead.
- Pilot log in the design doc; commit.
